# Excel Job Posting Analysis

## Welcome
This repository consists of two projects using Excel. [Public Job Posting Dataset](https://datanerd.tech) is used for data analysis using Excel. Luke Barousse's YouTube course inspired this project analysis approach.


### Project 1 - Interactive Dashboard
Built an interactive dashboard that consists of a lot of information for job seekers. 
### Project 2 - Job Posting Analysis 
In this project, PivotTable, Power Query, Power Pivot, and DAX are used to analyze the job posting dataset at an advanced level, answering business questions.
